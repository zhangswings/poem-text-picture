## 二、透明度阶梯

| 角色 | opacity | 说明 |
|---|---|---|
| 主体字 | 1.0 | 诗句主线，必须舒服可读 |
| 回声字 | 0.45–0.85 | 造形、重复、颜色承担者 |
| 气氛字 | 0.20–0.35 | 雨、雾、霜、雪点 |
| 底晕 | 0.04–0.08 | 超大号字，只做水墨底 |

## 三、SVG 技法片段

### 成阵（鸟群／鱼群）
同一词的 3–7 个副本，沿 V 形或斜线排，越远越小越淡：

```svg
<text x="600" y="140" font-size="26" fill="#d2367a" opacity=".85">啼鸟</text>
<text x="628" y="118" font-size="22" fill="#d2367a" opacity=".7">啼鸟</text>
<text x="658" y="142" font-size="19" fill="#d2367a" opacity=".55">鸟</text>
```

### 成线（风、雨、水流）
整串字一起旋转，逐字改角度、降透明度：

```svg
<text x="420" y="520" font-size="22" fill="#93a7b8" opacity=".45"
      transform="rotate(-32 420 520)">风雨声</text>
<text x="470" y="566" font-size="20" fill="#93a7b8" opacity=".38"
      transform="rotate(-32 470 566)">风雨声</text>
<text x="520" y="612" font-size="18" fill="#93a7b8" opacity=".30"
      transform="rotate(-32 520 612)">风雨声</text>
```

### 成峰（山脊＋远山）
同一「山」字，字号从 130 递减到 50，横排成脊；后排再加更小更淡的一列作远山：

```svg
<!-- 远山：小、淡 -->
<text x="120" y="330" font-size="46" fill="#b9c3cb" opacity=".55">山</text>
<text x="260" y="300" font-size="56" fill="#b9c3cb" opacity=".6">山</text>
<!-- 近山：大、浓 -->
<text x="330" y="400" font-size="128">山</text>
<text x="480" y="430" font-size="96">山</text>
```

### 成晕（水墨底）
```svg
<text x="360" y="820" font-size="460" fill="#5f7a3f" opacity=".045">春</text>
```

### 坠落（花、叶、雪、日）
逐字降低＋各自旋转，尺寸递减：

```svg
<text x="200" y="640" font-size="34" fill="#d98a9e" transform="rotate(22 200 640)">花落</text>
<text x="240" y="720" font-size="28" fill="#d98a9e" opacity=".8" transform="rotate(-14 240 720)">花落</text>
<text x="196" y="800" font-size="22" fill="#d98a9e" opacity=".6" transform="rotate(38 196 800)">花落</text>
```

## 四、构图主轨迹（先选一条，再排字）

| 轨迹 | 适合 | 排法 |
|---|---|---|
| 上升斜线 | 思乡、登高、春晓 | 从下左到上右，字块逐块抬高 |
| 弧线下坠 | 落日、落花、垂钓 | 起笔高、收笔低，角度越来越大 |
| 月轨（大 S） | 长诗、夜景 | 左盘上行 → 天心 → 右盘下行 → 底部横收 |
| 横向带状 | 江、河、潮、平原 | 一字带横穿，宽窄不一，中间留缺口 |
| Z 字折 | 山水远眺 | 顶横（山）→ 中横（水）→ 底横（岸），折处放点景 |

## 五、检查时最容易漏的两件事

1. **主体字被回声字淹没**：回声字只要一落到诗句主线上，就删掉它。
2. **点景不唯一**：一舟图里不该出现第二只船，一楼图里不该有第二座楼——除非诗里写了。

## 六、成体（字群堆剪影）参数表

| 物体 | 形状函数 | 填充字 | 参数 |
|---|---|---|---|
| 山 | 半宽 `W×(t^1.2)`，t 从峰顶 0 到山脚 1 | 山、千山 | 字号 26→12 随 t 递减；透明度 `(0.97−0.55d)(1−0.4t)`，d=离轴距离 |
| 船 | 甲板 `y=deck−15·sin(πx)`，船底 `y=deck+88·sin(πx)^0.6` | 蓑笠翁、孤舟 | 行内步长 = 字号×1.6；落字前判 `x+字宽×字数 < 右边界` |
| 云 / 雾 | 若干椭圆高斯叠合 | 云、霜、雾 | 字号 12–18，透明度 0.10–0.25，边缘更碎 |
| 花林 / 花堆 | 多个小圆簇 + 底部堆积 | 花、落、花落 | 簇心密、外围散；每朵旋转 −40°~+40° |
| 雪坡 | 一条上凸弧线到下边界 | 雪 | 近处字号大、远处小；底部渐稀 |

**雾化三圈**：物体边界外扩第 1 圈字号 ×0.8、透明度 ×0.6；第 2 圈 ×0.6、×0.4；第 3 圈 ×0.5、×0.25。

**主轴选择**：山水题用斜线（左上→右下）或 Z 字；夜景长诗用月轨；登高题用上升斜线。
