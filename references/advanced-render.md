# 高密度渲染（v4）：让字群真正堆成"体"

参考《登鹳雀楼》那张范例后总结的六条工程做法。它们解决的是同一个问题：**为什么同样是"用字画山"，有的图像剪影，有的像一堆噪点。**

## 一、形状用几何包含，不用概率撒点

```python
# ✗ 概率撒点：边缘毛糙、密度不均
if random.random() < 0.8: place(x, y)

# ✓ 几何包含：边缘由函数决定，干净
if inside(x, y): place(x, y)
```

山：`y >= ridge(x)`；河：`|y - center(x)| <= halfwidth(x)`；太阳：`dist <= R`；海：椭圆 + 波函数扰动；楼：阶梯函数 `top_k <= y <= top_k + 28`。

## 二、填实率 ≈ 95%

| 参数 | 取值 | 说明 |
|---|---|---|
| 字距 step_x | 字号 × 0.82 ~ 0.85 | 再小就糊成一坨 |
| 行距 step_y | 字号 × 0.80 ~ 0.82 | 中文方块字行距可比字距略紧 |
| 抖动 | ±1.2 px | 只有微抖，不要 3px 以上 |
| 每字旋转 | ±2° ~ ±8° | 去掉机械网格感，但别超过 8° |

对照：稀疏撒点（步长 ≈ 字号 × 1.6）在同样面积里少一半字，剪影立刻变"点阵"。

## 三、主字挖空（knockout）

大字直接压在字群上必然读不出。做法：**先把所有主字的占位矩形登记下来，填字时跳过这些矩形**，最后再把大字写上去。

```python
RES = [(x - 10, y - size*1.04, x + size*len(txt)*1.02 + 10, y + size*0.26) for 主字...]
...
if inside(x, y) and not any(r[0] <= x <= r[2] and r[1] <= y <= r[3] for r in RES):
    place(x, y)
```

效果：大字周围自然形成一圈白边，像刻出来的，比加描边干净得多。

## 四、三层剪影 + 山脚雾化

同一座山画三遍，越远越淡越疏：

| 层 | 颜色 | 字号 | 透明度 | 步长 |
|---|---|---|---|---|
| 远山 | `#b6c0c4` | 12 | 0.46 → 0.24 | 12.4 |
| 中山 | `#4f5a61` | 13 | 0.74 → 0.48 | 12.2 |
| 近山 | `#1b1f22` | 15 | 1.0 → 0.38 | 13.6 |

山脚必须化开，否则是一条硬直线：底边用 `foot(x) = base + 22·sin(x/170)`，并在其下加 30–40px 的更小更淡字作雾（透明度 0.22 → 0.08）。

## 五、色族分层（一色一义，族内做深浅）

| 物体 | 主色 | 浅色 | 用法 |
|---|---|---|---|
| 日 | `#b8471f` | `#d98a4a` | 核心实、外圈晕 |
| 河 / 海 | `#2a6489` | `#6f9cbd` | 河厚海薄，交界处用浅色过渡 |
| 山 | 三层灰墨 | — | 远淡近浓 |
| 楼 | `#6f4626` | `#a97b4e` | 踏板深、塔身浅 |

同一物体内部只变透明度与字号，不换色相——换色相就"脏"。

## 六、字群混排打散网格

同一片区域里按概率混入同族的另一个字（如太阳用 `日` 为主、30% 概率换 `白`；山用 `山` 但偶尔 `千山`），网格感立刻消失，且更贴原诗语汇。

## 七、四个常见坑

| 症状 | 原因 | 修法 |
|---|---|---|
| 山堆成灰带 | 山脊函数取 `max` 而非 `min`（y 向下，山顶是最小值） | `h = base; h = min(h, peak_value)` |
| 山是方块 | 半宽 = 全宽 × t^1.25 写反（t=0 应在峰顶，此时半宽必须为 0） | 检查 t 的方向 |
| 河像湖 | 半宽增长太快（0.19/px） | 0.06–0.08/px，入海口才放开 |
| 楼梯像斜条 | 踏板厚 62px 且级差 34px，上下粘连 | 踏板 28px、级差 44px，级间留 16px 白 |
| 大字被淹没 | 没做挖空 | 见第三节 |
